The Problem

Why One Number Lies

A leaderboard compresses a complicated experiment into one number. That number depends on which data entered the test set, which stayed in training, and how the model was initialized. Here's what we found.

Seed Variation

Same data, different random seed. The random forest's accuracy swung by 3.5 percentage points across 50 seeds.

Shared Splits

Three models, same 30 partitions. Logistic regression led on 28 of 30 splits — the clear winner here.

Experiment 2

A/A Testing

Same algorithm vs itself. A ≥1-point gap appeared in 61.9% of pairs when both seed and split changed.

Blocking Effect

Matching comparisons on shared splits gave a relative efficiency of 118.6%, cutting residual noise.

Design Insight

Why Blocking Matters

Comparing models on shared splits is like a paired t-test — it removes split-to-split noise, leaving a cleaner signal for the model difference.

118.6%
100% Relative Efficiency 150%

The completely randomized residual mean square was 1.186× the blocked residual. Shared splits cut noise — this is a sample-specific estimate on one dataset.

Randomized Block Model

Yij = μ + τi + βj + εij
i = model index j = split (block) τ = model effect β = block effect

One score per model-split cell means model-by-split interaction cannot be estimated separately from error.

Key Takeaways

What This Means for You

01

Never Trust a Single Run

Accuracy depends on which data entered the test set and how the model was initialized. A one-run "win" can vanish on the next run.

02

Report the Variation

Showing mean, SD, and range across seeds/splits turns a point estimate into honest uncertainty communication.

03

Use Matched Comparisons

Evaluating all models on the same splits (blocking) removes partition noise and makes differences interpretable as paired effects.

04

Mind the Granularity

With 114 test cases, each prediction changes accuracy by 0.877 pp. A 1-point difference might be one lucky guess.

05

A/A Tests Reveal Luck

When the same model shows a gap against itself, the gap isn't signal — it's the noise floor of the evaluation process.

06

Scope Your Claims

One dataset, one set of hyperparameters, accuracy as the sole metric. Honest science labels what it can and cannot support.

Methodology

How the Experiment Was Built

📊 Dataset

Breast Cancer Wisconsin Diagnostic — 569 cases, 30 real-valued features, binary diagnosis target. Selected for computational simplicity; not a clinical validation sample.

Wolberg et al. (1993), UCI Repository

🤖 Models

  • Logistic regression (standardized, max_iter=2000)
  • Decision tree (random_state varies)
  • Random forest (25 trees, random_state varies)
Fixed hyperparameters, no post-result tuning

🔬 Design

  • 50 estimator seeds on a 455/114 partition
  • 30 common stratified 80/20 splits
  • 1,000 A/A pairs in two conditions (D1/D2)
All splits stratified; accuracy = correct / total
